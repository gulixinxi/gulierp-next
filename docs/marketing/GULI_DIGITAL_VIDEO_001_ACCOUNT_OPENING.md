# 谷粒数字化 · 账号启动片 01 — 60s 脚本

> **片子代号:** `GULI_DIGITAL_VIDEO_001_ACCOUNT_OPENING`
> **片长:** 60 秒(±2s)
> **类型:** B 端账号启动片(故事型,非技术广告)
> **目标受众:** 工厂老板 / 门店老板 / 传统企业负责人
> **一句话定位:** 一个县城程序员,为什么开始帮助本地工厂老板做数字化升级?
> **情绪曲线:** 同情 → 共鸣 → 转折 → 价值 → 召唤
> **制作规格:** 真人出镜 + 真实工厂/门店素材 + 屏幕录制,可由 1 人 + 1 部手机完成拍摄

---

## 0. 创意说明

**为什么这套脚本能跑通**

- **钩子前置:** 前 3 秒是县城程序员自拍开场 + "我发现一个问题"——既是人设(县城),又是悬念(什么问题),3 秒留住人。
- **痛点具体不抽象:** 不说"数字化转型难",说"客户来了靠微信,库存靠 Excel,员工管理靠经验,老客户找不到记录"——每个画面都对应工厂老板的真实日常。
- **转折反常识:** "中小企业不需要一开始上几十万 ERP"——直击老板对 ERP 的恐惧(贵、复杂、上不动),建立"我们不一样"的人设。
- **解决方案可感:** CRM / 知识库 / AI 助手 / 网站——不是"赋能/打通/闭环"这种空话,是老板能秒懂的功能。
- **结尾召唤可执行:** 谷粒数字化 + 县城定位 + 更低成本——给老板一个具体的"找谁谈"的路径,不是"关注我"这种弱召唤。

**为什么这套脚本适合账号启动**

- 第一条视频要 **立人设**(县城程序员)+ **划赛道**(工厂/门店数字化)+ **给承诺**(更低成本)。
- 不需要炫技剪辑,真人出镜 + 真实场景就够。
- 60 秒内完成人设 + 痛点 + 转折 + 价值 + 召唤 = 标准启动片结构。

## 4. 分镜表(导演/拍摄/剪辑 直接照做)

### SCENE 01 — 钩子(0:00–0:05)

- **画面:** 县城清晨空镜(街景、早餐店飘着热气、小工厂烟囱)→ 切到程序员(你本人)站在街边或自己店门口,微微侧身,自然对镜头。
- **运镜:** 固定机位 / 半身 / 平视。手机自拍或三脚架均可。
- **光线:** 清晨自然光,逆光或侧光,带一点县城"烟火气"。
- **演员:** 你本人(老周)。穿着随意——polo 衫或格子衬衫,不要西装。
- **表情:** 平淡,带一点"我要说个真事"的开场感。**不要笑**——笑会冲掉"发现一个问题"的严肃。
- **动作:** 抬手轻拍一下胸口(指向自己,表示"我")即可。
- **声音:** 起 BGM(轻电子 + 一点点吉他, 不要太"广告")。

### SCENE 02 — 痛点 1:微信接单(0:05–0:08)

- **画面:** 工厂老板(或演员)坐在工作台前,手机亮屏,微信"客户来了"。
- **运镜:** 手持近景,轻微晃动(显得真实)。先拍老板疲惫的脸,再切到手机屏幕(用真实微信聊天界面,不是截图)。
- **演员:** 找一个本县的小工厂老板借场景/借脸(实在没有就用你自己演,但要换件衣服 / 戴副眼镜区分)。
- **道具:** 真微信 + 真聊天记录(脱敏)+ 真工厂背景。
- **字幕:** "客户来了——靠微信。"
- **声音:** 微信提示音 + 打字声。

### SCENE 03 — 痛点 2:Excel 对账(0:08–0:11)

- **画面:** 老板在仓库/办公桌前用 Excel 对库存。
- **运镜:** 过肩镜头(从老板肩膀后面拍 Excel 屏幕特写),然后拉远到全景(老板在大量货物/箱子中间,显得渺小)。
- **演员:** 同一个老板 / 你本人。
- **道具:** 真实 Excel 表格(故意留几个错乱的库存数字,显得真实)。
- **字幕:** "库存进了多少——靠 Excel。"
- **声音:** 键盘声 + 鼠标点击声。

### SCENE 04 — 痛点 3:经验管人(0:11–0:14)

- **画面:** 老板在车间里对一个工人说话,工人点头。
- **运镜:** 跟拍 / 手持,中景,自然光线。
- **演员:** 老板 + 1 个工人(可以是你 / 朋友扮演)。
- **字幕:** "员工管得怎么样——靠经验。"
- **声音:** 车间机器声(降低音量,作为氛围)。

### SCENE 05 — 痛点 4:翻不到记录(0:14–0:18)

- **画面:** 老板在手机上翻通讯录 / 翻微信聊天记录,表情有点急,翻来翻去。
- **运镜:** 特写手指在屏幕上滑动,镜头跟着手。
- **字幕:** "老客户三个月前下了什么单——翻不到记录。"
- **声音:** 心跳声 / 缓慢鼓点(开始压抑)。

### SCENE 06 — 转折(0:18–0:25)

- **画面:** 切到程序员(你本人),走进自己的办公室 / 工作台,坐下,打开电脑。镜头从门外/门外景推到电脑屏幕特写。

## 7. 后期 / 剪辑要点

- **节奏:** 痛点段(0:05–0:18)每句切一次镜头,快剪 + BGM 鼓点同步,显得"忙"和"乱"。转折后(0:25 起)放慢,每段价值展示 4–6 秒,留出"读"的时间。
- **转场:** 痛点段用硬切(匹配"硬"和"快"),价值段用溶解(0.3s),结尾用淡出。
- **配色:** 痛点段偏冷色(青灰),转折后偏暖(企业蓝 + 暖白),与品牌色一致。
- **字体字幕:** 思源黑体 Bold,白字 + 70% 黑底,字号屏幕高度 5%,逐字弹出 0.3s。
- **声音平衡:** 旁白 -3dB,BGM -12dB(始终在旁白之下),音效 -6dB(微信提示音、键盘声等,清晰可闻)。

## 11. 常见问题 / 备选版本

### Q1: 如果拍不出工厂真实场景怎么办?

**A:** 用 3 个替代方案:
- **方案 A(最佳):** 找 1 个本地小工厂(机械加工/食品/包装都行),给老板带 2 箱水果,说明来意,借 2 小时拍。**真人真场景永远比演员强。**
- **方案 B:** 拍"你自己版本的痛点"——用你家里的书桌、Excel、微信截图,讲"我朋友的工厂就是这样"。
- **方案 C:** 用 AI 生成的工厂图片(Midjourney / 即梦 / 可灵),配合真人出镜 + 屏幕录制,3 段穿插。

### Q2: 如果你不想真人出镜呢?

**A:** 有 2 个备选方案:
- **方案 A(声音出镜):** 全程只露手和电脑屏幕(屏幕录制 + 你的手在键盘上打字),声音是你的。适合内向型创始人。
- **方案 B(完全匿名):** 全部用屏幕录制 + 工厂空镜 + 字幕,无人出镜。账号头像是 Logo。适合品牌化运营。

### Q3: 如果 60 秒太长/太短呢?

- **太长:** 砍到 45s,删 SCENE 09(订单/库存)或 SCENE 10(网站),只留 CRM + AI 两个价值。
- **太短:** 砍到 30s,只留钩子 + 2 个痛点 + 1 个转折 + 1 个价值 + 召唤,适合抖音信息流。

### Q4: 县城口音问题?

- **保留:** 略带县城口音反而是"县城程序员"人设的加分项。视频号/抖音用户喜欢"真实"。
- **标准:** 如果你的普通话不差,建议保留自然语气,不要刻意学播音腔。

## 14. 这套脚本的"为什么能跑通"的复盘(给未来的你)

1. **钩子 = 县城 + 程序员 + 真人出镜。** 县城 + 程序员是稀缺人设,真人出镜 + 街景 = 真实感。3 秒留住"我是工厂老板 / 我也想看"的精准用户。
2. **痛点 = 4 句工厂老板的日常。** 不说"数字化难",说"客户在微信 / 库存在 Excel / 员工靠经验 / 老客户翻不到记录"——这 4 句每个老板都中过枪。
3. **转折 = 反常识。** "中小企业不需要几十万 ERP"——直击 ERP 恐惧(贵、复杂、上不动)。
4. **价值 = 4 个具体功能。** CRM / AI 助手 / 订单库存 / 网站——老板秒懂,不抽象。
5. **召唤 = 县城定位 + 更低成本 + 微信/官网。** 给一个具体"找谁谈"的路径,不是"关注我"。

> **如果第一条数据不好,改什么?**
> 1. 钩子前 3 秒(把"我在县城做企业数字化这些年"改成具体画面,比如直接拍工厂车间 + 一句"我帮这个老板做了数字化")。
> 2. 痛点段的"微信 / Excel / 经验"如果老板不感同身受,改成"应收账款 / 库存积压 / 工人流失"。
> 3. 转折段如果太抽象,加一句"我第一家客户的转型,只花了 X 块钱,3 个月回本"。
